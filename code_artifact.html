مهمتك يا بطل للصف الأول الإعدادي هي تخطي 40 كويكباً في زمن المضارع البسيط (Present Simple) باستخدام شفرات الحل الذكية بدون تعقيد!

من فضلك اكتب اسمك أولاً يا بطل لبدء المهمة!

دليلك السحري للحل بدون ترجمة!

مرحبًا القائد ! إليك الـ 6 مفاتيح للدرجة النهائية

حتى لو مش فاهم معنى الجملة، عيونك تدور على المفتاح وتختار الإجابة فوراً:

1. فريق المفرد بيحب حرف (S)

أول ما تلاقي الفاعل (He / She / It / أو اسم مفرد زي Ali) اختار الفعل اللي آخره (s / es / ies) أو has.

2. فريق الجمع بيحب الفعل سادة (مصدر)

أول ما تلاقي (I / We / You / They / أو اسم جمع زي Boys) اختار الفعل في المصدر بدون أي إضافات أو have.

3. شفرة النفي والسؤال (حرامي الـ S)

المفرد يأخذ doesn't / Does والجمع يأخذ don't / Do.
القاعدة الذهبية: بعد don't / doesn't / do / does لازم الفعل يرجع مصدر سادة!

4. خدعة كلمة (never) في النفي

كلمة never تنفي الجملة لكن مش بتسرق الـ S! يعني مع He / She / It الفعل بعدها يفضل بـ S عادي (مثل: He never comes late).

5. مكان ظروف التكرار (أصعب تركة!)

الكلمات (always / usually / often / sometimes / never) تأتي قبل الفعل العادي (usually plays)، لكن تأتي بعد am / is / are (is always).

6. امتى نختار (am/is/are)؟ وجداول المواعيد

لو الجملة مفيهاش فعل أصلي (فيها صفة أو اسم أو مكان زي happy / clever / at home) استخدم am/is/are. والقطارات والطائرات والامتحانات مفرد تأخذ فعل بـ S!

مفاتيح الحل السحرية (بدون ترجمة)

1. فاعل مفرد (He / She / It / اسم مفرد): نختار الفعل المنتهي بـ s / es / ies أو has.
2. فاعل جمع (I / We / You / They / اسم جمع): نختار الفعل في المصدر (سادة) أو have.
3. النفي والسؤال (don't / doesn't / Do / Does): المفرد يأخذ doesn't / Does والجمع يأخذ don't / Do، وبعدهم دائماً فعل في المصدر بدون أي إضافات.
4. خدعة never: تنفي الجملة لكن لا تحذف الـ S مع الفاعل المفرد!
5. مكان ظروف التكرار (always/usually/often/sometimes/never): تأتي قبل الفعل الأصلي (مثل: usually plays)، وتأتي بعد am / is / are (مثل: is always).
6. السؤال عن عدد المرات والوقت: إذا وجدت في الإجابة once / twice / three times / every اختر How often.
